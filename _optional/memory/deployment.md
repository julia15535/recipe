## Принципы (верификация и отладка прода)
- **Верифицируй деплой, не предполагай.** Добавь в health-эндпоинт версию/commit; после пуша
  поллируй health, пока commit не совпадёт. «Задеплоено» = подтверждено вживую, а не «запушено».
- Migrate-гейт ДО свапа (`set -e`): если live-версия поднялась и health 200 — миграция применилась.
- **Прод-ошибки минифицированы** — код ошибки расшифровывай из исходника пакета (dev-сообщение рядом
  с `formatErrorMessage(N)`); смотри логи контейнера; клиентские ошибки удобно слать на `/api/client-error`.
- **Код + docs — в ОДИН коммит:** docs-only коммит сразу после кодового сдвигает origin/main и ломает
  деплой-проверку по точному хэшу.
- Перед правкой/удалением на сервере — посмотри на цель; общие конфиги (nginx и т.п.) НЕ трогай без нужды.
