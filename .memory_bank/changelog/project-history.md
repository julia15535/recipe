## 2026-10-01 — Правки владельца к пробным экранам (план screens-owner-feedback)
Владелец посмотрела прототипы: поиск окном поверх страницы сначала попросила, затем оставила страницей
(по центру на компьютере); каталог — все 11 мест сразу, пустые бледные и не нажимаются (вариант Б);
вместо блока «Особенности состава» — строка «время + теги», у каждого тега свой цвет, без подписи;
«~ 4 порции» у ингредиентов. Две критики Codex. ADR-0020, ADR-0021. Отложено: «Избранное».

## 2026-10-01 — Экраны по решениям владельца (план home-and-recipe-screens)
Владелец надиктовала решения по главной и рецепту: поиск — лупой, первым — каталог (лента / список на
телефоне), без «−/+» порций — своё количество основного ингредиента, «пока без кбжу», метки-разделы
(11 разделов, «Разное» убрано), теги «Особенности состава». Три критики Codex (план, метки, теги).
ADR-0016…0019. Сделаны пробные экраны на демо-данных в `/admin/ui` (главная, поиск, рецепт), старая
пробная страница дизайна заменена списком экранов; e2e добавлен компьютерный вид 1280 px.
