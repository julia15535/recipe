# Product Brief — Книга рецептов (recipe)

> «Моя личная книга рецептов, где любой рецепт можно найти за несколько секунд, загрузить почти
> без ручного заполнения и мгновенно адаптировать под продукты, которые есть дома» — владелец.

## Для кого
- **Владелец** — ведёт книгу, добавляет рецепты.
- **Публичные пользователи** (родные, знакомые, Instagram) — по ссылкам ищут, читают, пересчитывают,
  без аккаунтов; сайт должен быть удобен и им.

## Ценность
Простой быстрый mobile-first сайт: поиск за секунды, пересчёт под свои продукты с КБЖУ,
добавление рецепта ИИ-импортом (текст, голос, фото, PDF/Word).
Питание: не строгий ЗОЖ — домашняя еда с разумным балансом, вкус важнее диеты.

## MVP (ТЗ §24)
Главная, каталог, категории, теги, поиск по названию и ингредиентам, страница рецепта (одна фото,
табы «Рецепт / Приготовление»), пересчёт по порциям и по ингредиенту, КБЖУ, вход владельца,
ИИ-импорт, предпросмотр и правка, автоперевод EN, SEO, мобильная версия.

## Не входит
Видео и фото шагов, соцсеть, комментарии, оценки, аккаунты посетителей, бренды ингредиентов,
версии рецепта, ИИ в поиске и пересчётах, копия интерфейса gotovim-doma.

## Критерии успеха (по приоритету)
1. Очень быстро найти рецепт. 2. Удобно готовить по рецепту. 3. Очень быстро добавить рецепт.
4. Удобно делиться. 5. SEO — вторично.
