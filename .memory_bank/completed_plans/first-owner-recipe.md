## Цель
Поставить первый настоящий рецепт владельца — «Вафли из творога» — на пробные экраны (`/admin/ui`), чтобы
она увидела его в «Завтраках», в поиске и на странице рецепта с пересчётом. Научить прототип того, что
есть в её рецепте: количество диапазоном («½–1 ч. л.»), строки «по желанию» (не пересчитываются), выход
в штуках («~ 4 шт.»), рецепт без времени.

## Источник задачи
Владелец, 02.10.2026: «давай я тебе рецепт скину и ты его один загрузишь?» + PDF + ответы «4 шт / время
не надо / только завтраки / фото позже» (`_intake/_processed/recipes/vafli-iz-tvoroga.md`).

## Рецепт (по шаблону)
Название «Вафли из творога»; описание — предложение агента («Несладкие творожные вафли на цельнозерновой
муке — с травами и специями»), поменять по слову владельца; раздел «Завтраки»; тег «Белок»; выход 4 шт.;
времени нет; фото — позже (заглушка). Ингредиенты: Творог 0,5% — 275 г (основной); Яйца — 2 шт.;
Цельнозерновая мука — 50 г; Разрыхлитель — ½–1 ч. л.; Соль — ½ ч. л.; Чёрный перец, итальянские травы или
паприка — по желанию. Шаги — её словами (на «ты»).

## Скоуп — что входит
- Демо-модель (`_demo/demo-types.ts`, критика Codex): у ингредиента количество `точное | диапазон | нет`
  отдельно от пометки (`по желанию` и т. п.) и единицы — чтобы было выразимо и «зелень — 10 г, по
  желанию»; правила: числа > 0, от ≤ до, основной ингредиент — только точное число. Выход — число +
  название изделия с формами («вафля / вафли / вафель», по умолчанию «порция») + признак
  «примерно» (у владельца «~» для порций — по умолчанию да). Время — необязательно. В будущей БД —
  десятичные/дробные числа, не float (follow-up).
- Показ: диапазон пересчитывается с обеих сторон («½–1 ч. л.» × 2 → «1–2 ч. л.»); простые дроби (¼, ⅓, ½,
  ⅔, ¾ и с целой частью — 1½) показываются дробями, только если значение им равно (сравнение с допуском
  10⁻⁶; 0,249 — не ¼) — это форма записи, не округление; «по желанию» — без числа и без пересчёта;
  выход — «~ 4 вафли» (формы слова по числу); рецепт без времени — строка только с тегами.
- Данные: рецепт `vafli-iz-tvoroga` в `_demo/demo-recipes.ts` (ключи поиска: Творог, Яйца, Мука).
- e2e: страница вафель — «½–1 ч. л.», «½ ч. л.», «по желанию» без числа, «~ 4 вафли», только тег «Белок»,
  часов нет; творог 550 г → яйца 4 шт., мука 100 г, «1–2 ч. л.», соль 1 ч. л., «~ 8 вафель», «по желанию»
  не меняется; 137,5 г → яйца 1 шт., «¼–½ ч. л.», соль ¼ ч. л., «~ 2 вафли»; вафли в «Завтраках» и в
  результатах по ингредиенту «Творог»; axe и без прокрутки вбок на странице вафель (длинная строка специй).
- Unit-тесты: дроби (в т. ч. 0,249 — не ¼, 1,5 — «1½»), диапазоны, формы слова выхода, инварианты модели.
- Память: `domain/screens.md` (рецепт без времени, выход в штуках), шаблон рецепта — в
  `domain/recipe-model.md` (диапазон, «по желанию», выход в штуках — нужны и в схеме БД).
