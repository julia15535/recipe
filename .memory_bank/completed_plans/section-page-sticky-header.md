## Цель
Третья правка прототипов по замечаниям владельца: раздел каталога открывает страницу раздела сразу с
рецептами (не поиск); шапка сайта закреплена при прокрутке на всех страницах; переключатель
«Рецептов: все / 3 / 0» убран, примерные рецепты всегда видны.

## Источник задачи
Владелец, 01.10.2026 — `_intake/_processed/brief/product-decisions-2026-10-01.md`, раздел «Замечания
владельца ко второй версии экранов» (текст как есть).

## Решено владельцем (дословно → смысл)
1. «нажимаю в каталоге на любой раздел, убери там поиск в начале, пусть сразу будут рецепты» → страница
   раздела: название раздела и карточки его рецептов, без формы поиска.
2. «при переходе на любые страницы шапка должна быть фиксирована» → шапка (название, лупа, язык)
   остаётся вверху экрана при прокрутке на всех страницах.
3. «Наверху почему-то появилось количество рецептов. Не понимаю зачем.» → переключатель убрать.
4. «верни их плиз временно» → все примерные рецепты видны всегда (переключатель запоминал «3»/«0» в
   браузере и прятал их).

## Решения агента (сообщаем)
- **Страница раздела** `/admin/ui/section/[id]` (на сайте позже — `/{locale}/catalog/{slug}`, ADR-0017):
  шапка, каталог, хлебные крошки «Главная / Супы», один видимый заголовок `h1` «Супы», карточки всех
  рецептов раздела (число рецептов не показываем — владелец его не просила). Текущий раздел в ленте и
  листе — заметно выделен, `aria-current="page"`, не ссылка на себя; пустой — бледный (ADR-0020), эти
  состояния не смешиваются. Прямой адрес известного пустого раздела — `h1` + «Пока нет рецептов»;
  неизвестный адрес — 404. Ссылки на разделы — из ленты, нижнего листа и строки разделов на рецепте.
  Уточнение в поиске (`?section=`) остаётся как было.
- **Шапка закреплена** (`sticky`, `top: 0`, слой `z-40` — ниже окон React Aria `z-50`), непрозрачный
  фон страницы и тонкая линия снизу; отступ сверху под «чёлку» (`env(safe-area-inset-top)`); высота
  (~68 px) — в CSS-переменной, `scroll-padding-top` у страницы, чтобы фокус и переходы к заголовкам не
  уходили под шапку. Полоска «Пробный экран» над шапкой прокручивается. Шапка добавляется и на страницу
  поиска. Лента каталога не закрепляется (иначе съест экран телефона).
- **Без переключателя:** всегда 11 разделов, из них 10 с рецептами, «Заготовки» — бледный (пример
  пустого раздела). Пустое состояние главной («Скоро здесь появятся рецепты») остаётся в коде для сайта.
  Старое значение в браузере владельца (`recipe-demo-mode`) больше никто не читает — оно ни на что не
  влияет; e2e проверяет это. ADR-0020 не меняется (переключатель был служебным, не решением).

- `components/site-header.tsx` (закрепление), `components/catalog/{catalog-ribbon,catalog-sheet,types}.tsx`
  (текущий раздел — `aria-current="page"`).
- `_demo/demo-catalog.ts` (адрес раздела → страница раздела), `recipe-intro.tsx` (ссылки разделов),
  `home-content.tsx`, `search-prototype.tsx`, `search/page.tsx` (шапка), `prototype-bar.tsx`.
- Удалить: `_demo/demo-mode.ts`, `_components/demo-mode-switch.tsx`, режимы в `demo-selection.ts`.
- e2e: раздел из ленты, листа и рецепта открывает страницу раздела — `h1`, крошки, карточки именно
  этого раздела, поля поиска нет; текущий раздел отмечен (телефон и компьютер); пустой раздел по
  прямому адресу — «Пока нет рецептов», неизвестный — 404; шапка есть на всех четырёх экранах, а
  «залипание» при прокрутке — на одном длинном экране для 375 и 1280 px; фокус по Tab не уходит под
  шапку; лист каталога после прокрутки открывается поверх шапки и возвращает фокус; старое значение
  `recipe-demo-mode=none` в браузере не прячет рецепты; переключателя «Рецептов» нет; режимы «3/0»
  из тестов удалить; axe, касания ≥ 44 px, без горизонтальной прокрутки — и на странице раздела.
  WebKit (движок Safari) — попробовать локально; окончательно «залипание» на iPhone проверяет владелец.
- Память: `core/ux.md`, `core/catalog.md`, `core/search.md` (раздел — не поиск), `.claude/rules/ui-rules.md`
  (шапка закреплена, слои, отступ под шапку).

## Скоуп — что НЕ входит
- Публичные `/ru`, `/en`, подразделы на странице раздела, сортировка/фильтры на странице раздела.

- Закреплённая шапка съедает высоту на телефоне (~68 px + «чёлка») — компактная, без лишних отступов.
- iOS Safari: «залипание» и восстановление прокрутки — проверка на реальном iPhone владельца.
