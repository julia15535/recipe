## Цель
Внести замечания владельца к прототипам (`/admin/ui`, план `home-and-recipe-screens`): поиск остаётся
отдельной страницей, на компьютере — красиво по центру; в каталоге сразу 11 мест, пустые разделы
бледные и не нажимаются, «оживают» с первым рецептом; на рецепте — одна строка «время + теги состава,
у каждого свой цвет» без подписи; порции — «~ 4 порции» у ингредиентов, без карточки справа.
Зафиксировать в ADR (дополняют ADR-0018, меняют показ из ADR-0019).

## Источник задачи
Владелец, 01.10.2026 вечер — `_intake/_processed/brief/product-decisions-2026-10-01.md`, разделы
«Замечания владельца к пробным экранам» и «Ответы владельца на план правок» (текст как есть).

## Решено владельцем (дословно → смысл)
1. «можно поиск отдельным окном оставить как сейчас, но сделай красиво по центру на компе. На телефоне
   все ок» → поиск — отдельная страница (ADR-0017 без изменений); на компьютере — по центру; телефон — как есть.
2. «Б: все 11 мест на ленте видны сразу, пустые разделы бледные и не нажимаются, а с первым рецептом
   «оживают»».
3. «иконочка вот 30 минут, рядом клетка, выдели цветом, потом железо выдели цветом» + «Цвет для тегов
   задай каждому свой по ассоциации … гармоничное» → строка: часы «30 мин» + теги, у каждого свой цвет.
4. «Убери текст, отмеченный автором…» → подписи нет.
5. «получится четыре порции, убери справа» + «~ 4 порции» → карточки справа нет; «~ 4 порции» у ингредиентов.

## Решения агента (сообщаем владельцу; поправит на пробном экране)
- **Поиск на компьютере:** форма — карточка по центру (ширина до 768 px): заголовок, «По рецепту / По
  ингредиенту», поле, «Уточнить»; результаты — ниже, тоже по центру (до 4 карточек в ряд). Телефон — без изменений.
- **11 мест каталога:** порядок постоянный (Завтраки … Заготовки). Пустой раздел — не ссылка, а
  обычный текст: бледные значок и название, название читаемое (контраст ≥ 4,5 : 1); в ленте — скрытая для
  глаз пометка «пока нет рецептов», в нижнем листе — видимая вторая строка «Пока нет рецептов», без
  стрелки. Совсем нет рецептов — все 11 бледные, на главной «Скоро здесь появятся рецепты», без
  подборки и «Популярного». В «Уточнить» поиска — только разделы с рецептами (фильтр; пустой — шум);
  непустых нет — группы «Раздел» нет; `?section=` пустого раздела не применяется — короткая
  пояснительная строка «пока пуст». Непустой = есть опубликованный рецепт в разделе или его подразделах.
- **Цвета тегов** (по ассоциации, приглушённые под оливу и персик; токены фон/текст/обводка в
  `styles/brand.css`, карта «стабильный id тега → токены» в коде; подписи — не ключи):
  | Тег (id) | Ассоциация | Фон / текст / обводка | Контраст текста |
  |-----|-----------|-------------|----|
  | Белок (`protein`) | персик — мясо, рыба, яйца, творог | `#ffe6d6` / `#8a4a22` / `#f3c4a6` | 5,7 |
  | Клетчатка (`fiber`) | олива — овощи, крупы | `#ecf0d7` / `#4d5b1a` / `#cdd6a0` | 6,4 |
  | Полезные жиры (`healthy-fats`) | золото — масло, орехи | `#f8ecc4` / `#6e5410` / `#e5d08a` | 6,1 |
  | Мало сахара (`low-sugar`) | пыльно-голубой — лёгкость | `#e3ebf2` / `#34536e` / `#b8cadb` | 6,7 |
  | Железо (`iron`) | ягодный — свёкла, гранат, печень | `#f3dfe8` / `#7a2e52` / `#ddb3c6` | 7,1 |
  Тег без своего цвета — нейтральный (техническая подстраховка). У группы — доступное имя «Особенности
  состава» (структура для экранного диктора, не оговорка). Без тегов — только время.
- **Порции:** справа от заголовка «Ингредиенты» — «~ 4 порции» (меняется сразу при вводе; диктор
  читает «примерно 4 порции»; одно `aria-live`, порции на странице — в одном месте; при неверном вводе —
  последнее верное).
- **Режим демо «Рецептов: все / 3 / 0»** — общий для главной и поиска (хранится в браузере; рецепты от него не зависят);
  «все» — 10 из 11 разделов активны («Заготовки» пусты), «первые» — 3 рецепта в 3 разделах, «ни одного» — 0.
  Добавить демо-рецепт со всеми пятью тегами (боул с лососем, киноа и авокадо), чтобы увидеть все цвета рядом. На компьютере рецепт — одна колонка по центру.
  Оговорку «пересчёт без округления — пример» — в полоску «Пробный экран» на рецепте.

## Скоуп — что входит
- **Поиск:** `search-prototype.tsx` — карточка по центру на ≥ lg, результаты по центру.
- **Каталог:** `components/catalog/types.ts` (+ признак «пустой»), `catalog-ribbon.tsx` (пустой — текст,
  не ссылка), `catalog-sheet.tsx` (то же, строка «Пока нет рецептов»), `catalog-nav.tsx`; демо: «непустые
  разделы» по демо-рецептам, переключатель в полоске «Рецептов: все / первые / ни одного»
  (`prototype-bar.tsx`, общий режим в браузере); пустое состояние главной; «Уточнить» — только непустые.
- **Рецепт:** `recipe-intro.tsx` — строка «часы + время + цветные теги», без заголовка и подписи;
  `recipe-body.tsx` — одна колонка, без правой колонки и карточки; `ingredients-panel.tsx` / заголовок —
  «~ N порций»; `demo-rescale.ts` — подпись порций с «~»; теги состава — стабильные id в демо-данных
  (`_demo/demo-catalog.ts`), цвета — `styles/brand.css` + `components/recipe/composition-tags.tsx`.
- **Проверки (e2e на production-сборке):** 1280 px — форма поиска по центру (центр карточки ≈ центр
  экрана); каталог в ленте и в листе в режимах «все / первые / ни одного»: N настоящих ссылок и 11 − N
  текстовых мест, пустые не получают фокус и не ведут никуда; в «Уточнить» — только непустые, без
  непустых — нет группы «Раздел», устаревший `?section=` сброшен; «ни одного» — «Скоро здесь появятся
  рецепты», нет подборки и «Популярного»; рецепт — нет «Особенностей состава», подписи и правой
  колонки; строка «время + теги», у каждого тега — его точные цвета (computed background/color);
  «~ 4 порции» (диктору — «примерно») → «~ 2 порции», при ошибке — последнее верное; axe без нарушений
  (wcag2a/aa, 21a/aa, 22aa) + расчётный контраст названий пустых мест; касания ≥ 44 px; без
  горизонтальной прокрутки на 375 px.
- **Память:** ADR-0020 (11 постоянных мест каталога, пустые бледные и не нажимаются, правило
  «непустой»; дополняет ADR-0018), ADR-0021 (рецепт: строка «время + теги состава, свой
  цвет у каждого» без подписи — меняет показ из ADR-0019; «~ N порций» у ингредиентов — совместимо с
  ADR-0016); `core/{ux,catalog,search}.md`, `domain/catalog-structure.md`, `.claude/rules/ui-rules.md` (токены тегов).

## Скоуп — что НЕ входит

- Публичные `/ru`, `/en`, схема БД, настоящий поиск, правила округления.

## Риски
- Бледные пустые места: бледнеют значок и фон, название остаётся читаемым — axe этого не гарантирует
  (проверка контраста расчётом в e2e).
- Пять цветов рядом могут спорить с оливой и персиком — проверяем на снимке, при нужде приглушаем.
- Без подписи теги читаются как обещание пользы — решение владельца; при рекламе/партнёрских продуктах
  пересмотреть (ADR-0019).
