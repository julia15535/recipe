## Цель
Два новых тега состава — «Омега-3» и «Антиоксиданты» (EN: Omega-3 · Antioxidants) — работают везде, где
работают нынешние пять: строка «Теги:» в тексте рецепта, подсказка ИИ при разборе, страница рецепта (свой цвет),
карточка (первый тег автора), фильтр в поиске, английская версия.

## Источник задачи
Владелец 06.10: «потом добавь еще тег омега3», затем «добавь еще тег антиоксиданты». Теги состава — ADR-0019,
показ — ADR-0021 / ADR-0030; правка каталога из админки ещё не сделана, поэтому новые теги — миграцией.

## Скоуп — что входит
- **База:** миграция `0011` (ручная, только данные): два тега с постоянными id и подписями ru + en.
  Позиции всех семи — абсолютными значениями (не «+1»), подписи — upsert по (тег, язык); несовпадение id и кода
  роняет миграцию; в конце проверка: ровно 7 кодов, нужный порядок, у каждого ru + en. Заодно EN «Fibre» → «Fiber»
  (ADR-0019: американский английский на весь сайт; в базе сейчас британский — несогласованность).
- **Порядок в фильтре поиска:** Белок · Клетчатка · Полезные жиры · **Омега-3** · Мало сахара · Железо ·
  **Антиоксиданты** (Омега-3 — рядом с жирами: по смыслу это их часть). На рецепте порядок — как у автора (не меняется).
- **Распознавание строки «Теги:»** (`lib/domain/catalog.ts`): «омега-3», «омега 3», «омега3» (просто «омега» —
  нет: бывает омега-6 и омега-9); «антиоксиданты», «антиоксидант». Типографские дефисы (‑ – —) в словах тегов
  приводятся к обычному. Подсказка «нет такого тега» (`lib/domain/recipe-text/issues.ts`) перечисляет все 7.
- **Цвета по ассоциации** (как у остальных, контраст текста ≥ 4.5:1, цель 5.5+): Омега-3 — **морская волна**
  (рыба, море; отличим от пыльно-голубого «Мало сахара»), Антиоксиданты — **черничный** (ягоды; отличим от
  ягодно-розового «Железо»). Токены `--color-tag-*` в `styles/brand.css`, классы — `components/recipe/composition-tags.tsx`.
- **ИИ (только подсказка, решает владелец — ADR-0019):** правило 6 промпта дополняется; версия промпта растёт;
  предел тегов в ответе ИИ — `TAG_CODES.length` в обеих схемах (было 5). Памятка «основа или одна из главных частей
  блюда; не посыпка, украшение, щепотка, масло для жарки или смазывания; сомневаешься — не ставь»:
  - **Омега-3:** жирная рыба (лосось, скумбрия, сельдь, сардина, форель), икра заметной порцией; из растений —
    лён, чиа, конопляное семя, грецкий орех, льняное / рапсовое масло, если их едят (заправка), а не жарят на них.
    Не ставить за креветки, кальмаров, гребешки, нежирную белую рыбу, слово «морепродукты»;
  - **Антиоксиданты** — узкий список явных случаев: тёмные ягоды как основа (черника, ежевика, чёрная смородина,
    клюква), гранат заметной частью, какао или тёмный шоколад как основной вкус, зелёный / чёрный чай или матча как
    основа напитка. Не ставить за обычный овощной салат, томаты, морковь, зелень, лимон, специи, шоколадную крошку.
  Источники (Codex, `external:codex`): NIH ODS Omega-3 fact sheet (жирная рыба; ALA — лён, чиа, грецкий орех, рапс;
  у креветок, трески, гребешков EPA/DHA мало); EFSA и NCCIH: «антиоксиданты» — не измеряемый нутриент, общие
  заявления о пользе не подтверждены → тег значит только «в рецепте заметно ягод / граната / какао / чая»,
  без слов о пользе (ADR-0019: при рекламе формулировки пересмотреть).
- **Проверки:** юнит — распознавание (три написания «Омега-3», типографский дефис, регистр, точка; НЕ
  распознаются «омега», «омега-6», «антиоксидантный»), схема ИИ: 7 разных тегов проходят, 8 — нет; БД-тест —
  точный порядок, id/код, ru + en у каждого; e2e — рецепт со строкой «Теги: омега-3, антиоксиданты»: оба тега
  своим цветом на рецепте, «Омега-3» первым на карточке, выбор в фильтре поиска (`?tag=…`), 320 px без прокрутки
  вбок, axe; образец `/admin/ui` — цвета всех 7. Живая проверка ИИ: + лосось (ждём «Омега-3»), + черничный смузи
  (ждём «Антиоксиданты»), + отрицательные (креветки, овощной салат, щепотка чиа / орех для украшения, шоколадная
  крошка) — новых тегов нет.
- **Цвета (Codex, контраст посчитать при реализации):** Омега-3 — фон `#DCEFE8`, текст `#245C52`, обводка
  `#9FCFC0` (≈6.4:1); Антиоксиданты — фон `#E9E3F3`, текст `#4A376D`, обводка `#C7B8DD` (≈8.1:1).
- **Выкладка:** пока старая версия сайта ещё отвечает (минуты переключения), сохранение рецепта ею потеряло бы
  новый тег (`lib/server/recipes/save.ts` пересобирает связи из распознанных) — владелец не правит рецепты, пока
  не скажу «готово». Английская страница уже переведённого рецепта берёт теги из снимка перевода
  (`lib/server/recipes/public-en.ts`) — после добавления тега старому рецепту нужно «Перевести заново».

### Уроки
- Живая проверка: первая формулировка поставила «Омега-3» салату с креветками и щепоткой чиа, хотя «не за креветки»
  было в правиле → строгость в описании тега («сам — только если основа…») и явное «НЕ omega-3, даже если блюдо из них».

  (anti-patterns №57).
