# Добавление рецепта — детали (ADR-0023, ADR-0024, ADR-0031; планы recipe-upload, recipe-ai-parse, ai-ingredients-from-list)

## ИИ-разбор (основной путь, ADR-0024)
- Поток: «Разобрать» → `aiParseRecipe` (`app/(admin)/admin/(protected)/recipes/ai-actions.ts`: `requireOwner()`,
  один разбор за раз, ≤ 30 в час — в памяти и по `recipe_imports`) → `parseWithAi` (`lib/server/ai/parse-recipe.ts`:
  ≤ 20 КБ) → шлюз (`lib/server/ai/gateway.ts`: `json_schema strict`, `reasoning_effort: low` для `openai/gpt-*`, таймаут — от вызывающего, без автоповторов;
  сбои — timeout/network/auth/rate/server/bad-response/refusal/length) → zod (`recipe-schema.ts`) → `fromAi`
  (`lib/domain/recipe-text/from-ai.ts`) → проверка, что аккуратный текст ≤ 20 КБ → `recipe_imports` (сутки) → предпросмотр.
  «Сохранить» (`saveParsedRecipe`) берёт разбор по id, перепроверяет (`isSavable`), сохраняет и удаляет разбор;
  `source_text` = `toCanonicalText` (`canonical.ts`), `original_text` = вставленный текст. Таймаут шлюза 45 с (меньше 60 с
  прокси); версия промпта — в логе (`task`).
- Инструкция (`lib/server/ai/recipe-prompt.ts`, версия в коде): текст — документ, не команды; `not_recipe`; ничего не
  выдумывать, слова автора в шагах дословно (с уточнениями, граммами, температурами); слова → числа с цитатой в
  `changes`; без количества — «по вкусу» (специи, соль), «для жарки», «для панировки», «для подачи» или пусто;
  единицы как у автора (ложки в граммы не переводить, «примерно 3 г» в скобках при ложках не переносить);
  основной — ТОЛЬКО отмеченный автором; разделы и теги — только из списков.
- Список автора (ADR-0031): ИИ отвечает `ingredients_source` (поле схемы перед `ingredients`). `list` — отдельное
  перечисление (строки, маркеры, «Нужно: …» через запятую) → ингредиенты только из него, в его порядке и с его
  количествами; ингредиент из шагов вне списка, другое количество, добавка «ещё 1 ч. л., если…» — в `doubts` (≤ 5, по
  одному на ингредиент; вода для варки не в счёт); шаги дословно, добавка в советы не уходит. `text` — из всего
  текста. Замечания нашего кода (`lib/domain/recipe-text/ai-checks.ts`, тест `ai-checks.test.ts`): `text` → «Списка
  ингредиентов не было — …» (`sourceNote`); одно название в нескольких строках → «есть в списке 2 раза — нужны ли
  обе строки» (`repeatNotes`: регистр, «ё», «яйцо/яйца»; условие «если…/по желанию» не различает, назначение «в
  тесто/для жарки» и уточнение в скобках — различают). Оба — `note`, сохранить не мешают.
- Основной от ИИ сверяется с текстом (`confirmMain` в `from-ai.ts`): в строке/предложении автора рядом с
  ингредиентом должна быть пометка «основн…»; нет — рецепт без пересчёта (ADR-0025).
- Примерный вес/объём в пометке при количестве («примерно 3 г», «280 г», «75 мл / 65–70 г») убирается —
  `lib/domain/recipe-text/notes.ts` (и в ИИ-пути, и в старом формате); без количества пометка остаётся.
- «Проверьте» (`Check.group`): `decide` — блокирует сохранение (не рецепт, нет названия/раздела/ингредиентов/шагов,
  название > 120 знаков, два основных, основной не точным числом, непонятное количество; аккуратный текст > 20 КБ —
  отказ в `ai-actions.ts`); `changed` — цитаты (`quote` сверяется с текстом, нет в тексте → `note`), раздел; `note` —
  основной или «без пересчёта», ингредиент без числа, сомнения ИИ, неизвестные единицы, непонятый выход. Слово без числа в единице
  («щепотка») становится пометкой.
- Проверка модели вручную: `RECIPE_AI_EVAL=1 AI_GATEWAY_API_KEY=… pnpm vitest run lib/server/ai/recipe-eval.live` на
  `scripts/ai-eval/*.txt` (15 текстов: абзацы, переносы PDF, без количеств, единицы, длинные шаги, советы, напиток,
  заготовка, инъекция, не рецепт, список + добавка в шаге, «Нужно: …» в абзаце) — числа в шагах и советах только из
  текста; у списков — точные строки «название|количество|единица» по порядку (`lib/server/ai/recipe-eval.expected.ts`),
  абзацы — с замечанием «списка не было». Замер 03.10 (версия 2026-10-03.1): 15/15. Менять промпт/модель — только с этим прогоном.
- Совместимость схемы: Gemini (`google/gemini-3.1-flash-lite`) не принимает `type: ["object","null"]` — при смене
  провайдера проверить схему.

## Экраны кабинета
- `/admin` — «Мои рецепты» (`app/(admin)/admin/(protected)/recipes/_components/recipe-list.tsx`): название, когда
  меняли, «Черновик» / «Опубликован»; «Добавить рецепт».
- `/admin/recipes/new`, `/admin/recipes/[id]/edit` — `recipe-editor.tsx`: поле «Рецепт» → «Разобрать» (ИИ) →
  «Проверьте» (`ai-checks.tsx`) + предпросмотр → «Сохранить черновик» / «Опубликовать» (новый) или «Сохранить»
  (правка: статус и адрес не меняются). Сбой ИИ или ключа нет → «Разобрать по старому формату» → «Что поправить»
  (`parse-issues.tsx`). С пунктами «нужно решить» / ошибками кнопки сохранения неактивны.
- `/admin/recipes/[id]` — как на сайте (с блоком «Советы») + статус + «Изменить», «Опубликовать» / «Снять с
  публикации», «Удалить» — только черновик, с подтверждением; у опубликованного — «Открыть на сайте» (`recipe-actions.tsx`).
  Разделы здесь не ссылки (`buildView(…, null)` в `queries.ts`).

## «Старый формат» — разбор без ИИ (`lib/domain/recipe-text/`)
- Блоки (`blocks.ts`): первая свободная строка — название («Рецепт Творожные вафли» → «Творожные вафли»;
  «Рецепт вафель…» — как есть); строки «ключ:» — «Теги/Разделы», «Описание», «Время» (до 60 знаков),
  «Выход/Порции», «Название» — в шапке и среди ингредиентов, но не в шагах (там это текст шага);
  «Ингредиенты:» → «Приготовление:» → «Советы:». Остальные строки шапки — описание
  (вместе с «Описание:»; при «Название:» и первая свободная строка); строка с маркером в шапке начинает
  ингредиенты, если «Ингредиенты:» нет. Выход «4 вафли» — предупреждение: слово не склоняется.
  Советы — «Советы:» (≤ 20 по ≤ 1000 знаков, иначе ошибка).
- Теги (`lib/domain/catalog.ts`): слово → раздел (порядок, первый — основной) или тег состава; иначе
  предупреждение. Без раздела — ошибка.
- Ингредиент (`ingredient-line.ts`): маркеры ●•*·, «-» с пробелом, «1.»; разделитель «—», «–», «:» или «-» с
  пробелами; количество справа (целое, «0,5», «½», «1½», «⅓», «1/2», диапазон «½–1»); без разделителя —
  только «число + известная единица» в конце («молоко 1ст л»). Единицы (`units.ts`) → «ст. л.», «ч. л.», «г»,
  «кг», «мл», «л», «шт.», «стак.», «щеп.», «зуб.», «пуч.»; неизвестная — как написана + предупреждение.
  После разделителя без числа — только «щепотка», «щепоть», «по вкусу», «по желанию», «на кончике ножа», «для подачи»,
  «для смазывания» (иное слово — непонятная строка); строка без числа с пометкой в скобках — «без количества» с этой
  пометкой (`ingredient-line.ts`). Скобки —
  пометка; «основной ингредиент» / «(основной)» — основной; «Яйца — 2, крупные» — без единицы, «крупные» — пометка.
- Советы: блок «Советы:» → `draft.tips` (≤ 20, ≤ 1000 знаков) → `recipe_tips`, показ — блок «Советы» во вкладке
  «Приготовление» (`components/recipe/recipe-body.tsx`).
- Шаги: «1.», «1)», «1:», «1 —» (так пишет владелец, 02.10), «Шаг 1», маркер; несколько шагов в одной строке
  делятся перед «N. Заглавная» / «N — Заглавная»; строка без номера — новый шаг, а приклеивается (с
  предупреждением) только оборванная (без точки в конце, следующая с маленькой буквы — перенос PDF); строка из
  одного маркера пропускается; заголовок можно с текстом («Приготовление: 1. …»); текст — дословно.
- Ошибки (сохранять нельзя): нет названия, раздела, ингредиентов, шагов; два основных, основной не точным
  числом; непонятная строка; пределы. Предупреждения: основной не отмечен (рецепт без пересчёта), ингредиент без
  количества (строка без числа). Замечание — `{code, severity, line, raw, message}` (`issues.ts`); у замечаний о
  строке ингредиента — номер и сама строка.
- Пределы (`limits.ts`): 20 КБ в байтах UTF-8, 300 строк по ≤ 2100 знаков (шаг абзацем + номер), название ≤ 120, ингредиентов ≤ 60
  (имя ≤ 200, пометка ≤ 300, единица ≤ 30), шагов ≤ 40 (≤ 2000), без управляющих символов.

## Сохранение
- Server Actions (`app/(admin)/admin/(protected)/recipes/actions.ts`): `previewRecipe`, `saveNewRecipe`,
  `saveRecipeText`, `changeRecipeStatus`, `removeDraft` — каждое `requireOwner()`; сохранение заново разбирает
  присланный текст (готовые данные от браузера не берутся); сбой БД (`StorageError`) → «Не получилось
  сохранить — попробуйте ещё раз. Текст на месте.»; нет связи — «Нет связи с сайтом — проверьте интернет и нажмите
  ещё раз. Текст на месте.» (`recipe-editor.tsx` `OFFLINE`). После каждой успешной записи
  (и в `ai-actions.ts` `saveParsedRecipe`) — `refreshPublicSite()`: сброс кэша сайта (ADR-0027).
- `lib/server/recipes/` — без проверки владельца (её делают страницы и действия): `save.ts` (новый рецепт и
  замена — одна транзакция; slug — `lib/domain/recipe-text/slug.ts`, совпадение → `-2` через savepoint;
  замена по `revision`, иначе «изменён в другой вкладке»), `status.ts` (`published_at` — первая публикация,
  не очищается; любая смена → `revision + 1`; удаление только черновика), `queries.ts`, `catalog.ts`.
- Ошибки БД — `StorageError` без параметров запроса (`lib/server/db/errors.ts`).

## Схема (миграции `drizzle/0002`…`0006`)
`recipes` (статус, `source_text` ≤ 20480 байт — аккуратный текст, `original_text` — вставленный как есть для ИИ,
`revision`, `main_ingredient_id` (может быть NULL — без пересчёта, миграция 0005) и `primary_section_id` —
отложенные составные FK на свои строки, выход — дробь) ·
`recipe_localizations` (ru — из текста, en — из перевода, ADR-0029 и `domain/recipe-model.md`; slug UNIQUE по локали, ≤ 80) · `recipe_sections` / `recipe_composition_tags` (порядок) ·
`recipe_ingredients` (дроби `amount_num/den`, `amount_max_*`; CHECK exact/range/none, min ≤ max; none — пометка
необязательна, миграция 0006) · `recipe_steps` ·
`recipe_tips` (≤ 1000) · `recipe_imports` (разборы ИИ: исходный текст + `result` jsonb, сутки; сохранение удаляет
разбор — дубля не будет) · `sections` / `composition_tags` + локализации — 11 разделов и 5 тегов (uuid5 от code).
Правка «по старому формату» не стирает `original_text`.

## Дроби и пересчёт
`lib/domain/fraction.ts` (сокращение, `parseNumber`), `lib/domain/rescale.ts` (коэффициент — дробь; показ —
десятичный, `formatAmount`: половины и четверти точно «0,5» / «1,25», трети «0,3», ADR-0030); после пересчёта показ округляет `lib/domain/rounding.ts`
(ADR-0026). Общие компоненты `components/recipe/{recipe-intro,recipe-body,
ingredients-panel}.tsx` на модели `components/recipe/view.ts`; прототипы — адаптером `_demo/demo-view.ts`.
