# Загрузка рецепта текстом — детали (ADR-0023, план recipe-upload)

## Экраны кабинета
- `/admin` — «Мои рецепты» (`app/(admin)/admin/(protected)/recipes/_components/recipe-list.tsx`): название,
  когда меняли, «Черновик» / «Опубликован»; «Добавить рецепт».
- `/admin/recipes/new`, `/admin/recipes/[id]/edit` — `recipe-editor.tsx`: поле → «Проверить» → «Что поправить»
  (`parse-issues.tsx`) + предпросмотр (те же `components/recipe/*`, что у прототипов) → «Сохранить черновик» /
  «Опубликовать» (новый) или «Сохранить» (правка: статус и адрес не меняются). С ошибками кнопки неактивны.
- `/admin/recipes/[id]` — как на сайте + статус + «Изменить», «Опубликовать» / «Снять с публикации»,
  «Удалить» — только черновик, с подтверждением (`recipe-actions.tsx`).

## Формат текста (`lib/domain/recipe-text/`)
- Блоки (`blocks.ts`): первая свободная строка — название («Рецепт Творожные вафли» → «Творожные вафли»;
  «Рецепт вафель…» — как есть); строки «ключ:» — «Теги/Разделы», «Описание», «Время» (до 60 знаков),
  «Выход/Порции», «Название» — в шапке и среди ингредиентов, но не в шагах (там это текст шага);
  «Ингредиенты:» → «Приготовление:» (→ «Советы:» — пока предупреждение). Остальные строки шапки — описание
  (вместе с «Описание:»; при «Название:» и первая свободная строка); строка с маркером в шапке начинает
  ингредиенты, если «Ингредиенты:» нет. Выход «4 вафли» — предупреждение: слово не склоняется.
- Теги (`lib/domain/catalog.ts`): слово → раздел (порядок, первый — основной) или тег состава; иначе
  предупреждение. Без раздела — ошибка.
- Ингредиент (`ingredient-line.ts`): маркеры ●•*·, «-» с пробелом, «1.»; разделитель «—», «–», «:» или «-» с
  пробелами; количество справа (целое, «0,5», «½», «1½», «⅓», «1/2», диапазон «½–1»); без разделителя —
  только «число + известная единица» в конце («молоко 1ст л»). Единицы (`units.ts`) → «ст. л.», «ч. л.», «г»,
  «кг», «мл», «л», «шт.», «стак.», «щеп.», «зуб.», «пуч.»; неизвестная — как написана + предупреждение.
  Без числа — только «щепотка», «щепоть», «по вкусу», «по желанию», «на кончике ножа», «для подачи», «для
  смазывания» (после разделителя или в скобках); прочая пометка в скобках количество не заменяет. Скобки —
  пометка; «основной ингредиент» / «(основной)» — основной; «Яйца — 2, крупные» — без единицы, «крупные» — пометка.
- Шаги: «1.», «1)», «1:», «1 —» (так пишет владелец, 02.10), «Шаг 1», маркер; несколько шагов в одной строке
  делятся перед «N. Заглавная» / «N — Заглавная»; строка без номера — новый шаг, а приклеивается (с
  предупреждением) только оборванная (без точки в конце, следующая с маленькой буквы — перенос PDF); строка из
  одного маркера пропускается; заголовок можно с текстом («Приготовление: 1. …»); текст — дословно.
- Ошибки (сохранять нельзя): нет названия, раздела, ингредиентов, шагов; не отмечен основной (подсказка
  кандидата и его строки), два основных, основной не точным числом; ингредиент без количества и пометки;
  непонятная строка; пределы. Замечание — `{code, severity, line, raw, message}` (`issues.ts`); у замечаний о
  строке ингредиента — номер и сама строка.
- Пределы (`limits.ts`): 20 КБ в байтах UTF-8, 300 строк по ≤ 2000 знаков (шаг абзацем), название ≤ 120, ингредиентов ≤ 60
  (имя ≤ 200, пометка ≤ 300, единица ≤ 30), шагов ≤ 40 (≤ 2000), без управляющих символов.

## Сохранение
- Server Actions (`app/(admin)/admin/(protected)/recipes/actions.ts`): `previewRecipe`, `saveNewRecipe`,
  `saveRecipeText`, `changeRecipeStatus`, `removeDraft` — каждое `requireOwner()`; сохранение заново разбирает
  присланный текст (готовые данные от браузера не берутся); сбой БД (`StorageError`) → «Не получилось
  сохранить — попробуйте ещё раз. Текст на месте.»; нет связи — то же в редакторе.
- `lib/server/recipes/` — без проверки владельца (её делают страницы и действия): `save.ts` (новый рецепт и
  замена — одна транзакция; slug — `lib/domain/recipe-text/slug.ts`, совпадение → `-2` через savepoint;
  замена по `revision`, иначе «изменён в другой вкладке»), `status.ts` (`published_at` — первая публикация,
  не очищается; любая смена → `revision + 1`; удаление только черновика), `queries.ts`, `catalog.ts`.
- Ошибки БД — `StorageError` без параметров запроса (`lib/server/db/errors.ts`).

## Схема (миграции `drizzle/0002_recipes.sql`, `0003_recipes_constraints_seed.sql`)
`recipes` (статус, `source_text` ≤ 20480 байт, `revision`, `main_ingredient_id` и `primary_section_id` — отложенные
составные FK на свои строки, выход — дробь) · `recipe_localizations` (ru; slug UNIQUE по локали, ≤ 80) ·
`recipe_sections` / `recipe_composition_tags` (порядок) · `recipe_ingredients` (дроби `amount_num/den`,
`amount_max_*`; CHECK exact/range/none, min ≤ max) · `recipe_steps` · `sections` / `composition_tags` +
локализации — 11 разделов и 5 тегов с постоянными id (uuid5 от code), подписи и slug ru.

## Дроби и пересчёт
`lib/domain/fraction.ts` (сокращение, `parseNumber`), `lib/domain/rescale.ts` (коэффициент — дробь; «½», «⅓»
у ложек и штук; остальное — до десятых). Общие компоненты `components/recipe/{recipe-intro,recipe-body,
ingredients-panel}.tsx` на модели `components/recipe/view.ts`; прототипы — адаптером `_demo/demo-view.ts`.
