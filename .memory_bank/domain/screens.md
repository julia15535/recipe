# Экраны сайта — детали (решения владельца 01.10)

> Прототипы на примерных рецептах — `app/(admin)/admin/ui/` (`/admin/ui/home`, `/section/[id]`,
> `/search`, `/recipe/[slug]`), проверки — `e2e/prototypes.spec.ts`. Публичные `/ru`, `/en` получат эти
> экраны вместе со схемой БД (адреса — ADR-0017).

## Шапка (все страницы)
Название (на главную) · лупа «Поиск» (на телефоне — только значок) · язык. **Закреплена** при прокрутке
(`components/site-header.tsx`: `sticky`, `z-40` под окнами React Aria; отступ под «чёлку» заготовлен —
действует при `viewport-fit=cover`; высота 72 px — `--site-header-height` и `scroll-padding-top` в
`app/globals.css`). Под шапкой ничего не закрепляем.

## Главная
- Первым — каталог (ADR-0018, ADR-0020): всегда 11 мест в постоянном порядке; пустой раздел — бледный,
  не ссылка («пока нет рецептов»); компьютер (от 1024 px) — лента на всю ширину, телефон и планшет —
  кнопка «Каталог» → нижний лист (`components/catalog/catalog-nav.tsx`).
- Ниже — «Подборка недели» (название и рецепты выбирает владелец), «Популярное» — в самом низу (на сайте
  пока скрыто: нужен счётчик открытий). Нет рецептов — «Скоро здесь появятся рецепты».

## Страница раздела
Владелец: «убери там поиск в начале, пусть сразу будут рецепты». Крошки «Главная / Супы», заголовок,
карточки всех рецептов раздела (в т. ч. где раздел не основной); каталог с выделенным текущим разделом
(`aria-current`, не ссылка). Пустой раздел по прямому адресу — «Пока нет рецептов»; неизвестный — 404.

## Поиск
Отдельная страница (окно поверх — владелец отклонила 01.10): «По рецепту / По ингредиенту», поле,
«таблетки» ингредиентов, «Уточнить» (разделы с рецептами + теги состава; свёрнуто, открыто сразу, если
раздел задан в адресе); на компьютере — карточкой по центру, результаты под ней. «Назад» — туда, откуда пришли (Navigation API), иначе на главную.

## Рецепт
- Шапка: разделы строкой ссылок → страницы разделов; название; описание; строка «часы + время + теги
  состава, у каждого свой цвет» без подписи (ADR-0021, `components/recipe/composition-tags.tsx`); фото.
- Вкладки «Рецепт / Приготовление». «Ингредиенты» и справа «~ N порций»; у основного ингредиента — поле
  «своё количество», остальное и порции пересчитываются (ADR-0016), без «−/+». КБЖУ пока нет (ADR-0019).
- На компьютере — одна колонка по центру.
