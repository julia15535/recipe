# Поиск — спецификация (ТЗ §3, §5 + продуктовые решения)

> При расхождении ТЗ и продуктовых решений — решения владельца (они позже), см. `source-of-truth.md`.

## Приоритет
№1 сценарий продукта — **максимально быстро найти конкретный рецепт**. «Что приготовить из того,
что есть дома» — НЕ основной сценарий (мульти-ингредиентный поиск есть, но главную под него не строим).

## Главная — переключатель режимов
- **По рецепту** — по названию блюда; автокомплит.
- **По ингредиенту** — один или несколько ингредиентов одновременно (выбранные — «фишками»),
  автокомплит `тво… → творог`.
- На главной **не** показывать огромный каталог ингредиентов — интерфейс простой.
- Максимально быстро, особенно с мобильного; всё управляется пальцем, без desktop-dropdown.

## Иерархия ингредиентов в поиске
- Запрос по родителю находит всех потомков: «сыр» → рецепты с моцареллой, пармезаном, чеддером,
  сливочным сыром и просто «сыром».
- Запрос по конкретному типу — только его: «моцарелла» → только рецепты с моцареллой.
- Несколько ингредиентов — пересечение (И): курица + грибы → рецепты, где есть оба.

## Уточнение результатов (ТЗ §3)
- После ввода «курица» — варианты с группировкой по категориям: все рецепты с курицей; закуски
  с курицей; салаты с курицей; супы; вторые блюда; выпечка и т. д.
- Вложенная фильтрация без отдельной сложной формы: `курица + грибы → Вторые блюда`.
- После выбора ингредиента — сразу результаты, затем можно ограничить категорией или тегом.
- Поиск также по категории, подкатегории, тегам и сочетаниям условий.

## Тег внутри категории (ТЗ §5)
- `Супы → Полезное питание` — сначала рецепты текущей категории с этим тегом.
- На той же странице одним нажатием переключить категорию (Закуски, Салаты, Супы…) — **тег остаётся
  активным**.

## Без ИИ
Обычный поиск — индексация ингредиентов, категорий, тегов и синонимов. ИИ в поиске не используем,
пока задача решается индексом.

## Открытые вопросы (решать в плане поиска)
- Где живёт индекс: сервер (PostgreSQL: pg_trgm + полнотекст с русской морфологией) или компактный
  клиентский индекс (для сотен–тысяч рецептов даёт мгновенный отклик офлайн). Замерить.
- Опечатки и словоформы («творогом», «сыры») — синонимы в справочнике vs морфология БД.
- Поиск по EN-версии на `/en/`.
