## Цель
1. На карточке рецепта (главная, раздел, поиск; ru и en) рядом с названием — один тег состава: первый из тегов автора,
   своим цветом, как на странице рецепта.
2. Количества ингредиентов — десятичными вместо дробей: «1,5 ст. л.» вместо «1½», ½ → 0,5, ¼ → 0,25, ¾ → 0,75,
   трети → 0,3 / 0,7 (по-английски — с точкой: 1.5 tbsp).

## Источник задачи
Владелец 03.10 (скриншот английской главной): «давай в меню рядом с названием добавим один важный тег, типа белковый и
прочее?», «в ингредиентах замени дроби на десятичные, типа 1,5 ст. л.»; ответы: тег — «Первый из моих»; трети —
«0,3 и 0,7».

## Решения
- Тег: первый по порядку автора (`recipe_composition_tags.position`, название на языке страницы); на `/en` — первый из
  снимка перевода (`tagCodes[0]`, английское название; нет названия — тег не показываем). В данных карточки —
  `tag: { id, label } | null` (коды тегов для фильтра поиска — отдельно). Показ — строка под названием: время и тег
  (`flex-wrap`, тег и без времени; как «время + теги» на странице рецепта, ADR-0021), компонент
  `components/recipe/composition-tags.tsx`. Прототипы — `composition[0]`.
- Десятичные: меняется только показ (`formatAmount` в `lib/domain/rescale.ts`, `quarters` в `lib/domain/rounding.ts` —
  с языком): половины и четверти — точно (0,5 / 0,25 / 0,75 / 1,25 / 1,75 — не «1,3» для 1¼), трети — до десятых
  (0,3 / 0,7 / 1,3); диапазоны — оба конца; «щепотка» — словом; большие числа — с разделением тысяч; по-английски —
  с точкой. Округление пересчёта (ADR-0026: ложки — до ¼ и ½) не меняется. Не трогаем: текст шагов автора, канонический
  текст рецепта (`lib/domain/recipe-text/canonical.ts` хранит точную `1/3`), разбор и метки перевода. Ввод основного —
  как был; «Как в рецепте» ставит коэффициент ровно 1 (сейчас для основного ⅓ получалось 0,999).

## Скоуп — что входит
`lib/server/recipes/public-lists.ts`, `public-en.ts` (тег карточки и записи поиска), `components/recipe/recipe-card.tsx`,
`app/(public)/[locale]/_components/cards.ts`, адаптер прототипов; `lib/domain/{rescale,rounding}.ts` + тесты;
ожидания e2e («≈ ½ ч. л.» → «≈ 0,5 ч. л.»); память — ADR-0030 (десятичные и тег на карточке; уточняет ADR-0021 и
ADR-0026), `domain/screens.md`, `core/rescaling.md`, `domain/rounding-rules.md`.

## Критерии приёмки
- [ ] Карточки на главной, в разделе и поиске (ru, en) — первый тег автора своим цветом (тест БД: два тега в порядке,
  обратном каталожному); 375 px — длинное название, время + длинный тег, без времени, без тега — без прокрутки, axe
- [ ] Рецепт и пересчёт: «1,5 ст. л.», «1,25 ч. л.», «0,3 стак.»; по-английски «1.5 tbsp»; диапазон «0,5–1 ч. л.»;
  «щепотка»; «1 500 г»
- [ ] lint / typecheck / test / test:db / e2e; память, audit «чисто»
