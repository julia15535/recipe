## Цель
Поставить проекту настоящую дизайн-систему — **Untitled UI React** (Tailwind 4 + React Aria),
взятую из **исходного** репозитория github.com/untitleduico/react (MIT), со **своей** тёплой палитрой
для еды. Заглушка каркаса (shadcn base-nova + временные токены) уходит, пока на ней ничего не построено.

## Источник задачи
Владелец (29.09): «дизайн-систему брал? Если надо — возьми remlab» → затем: «да (UUI), но цвета
другие, тёплая палитра; цвета remlab не переносить, кастомные элементы remlab не брать — загрузить
изначальный исходник и продумать палитру с нуля, можно оливково-зелёный». Критика Codex 29.09
(`external:codex`, 11 замечаний) — внесена.

## Решения (→ ADR-0015, заменяет строку UI в ADR-0011)
| Что | Выбор | Почему |
|-----|-------|--------|
| Система | Untitled UI React, бесплатная MIT-часть, копия из upstream с зафиксированного коммита (сейчас `4702dc0ea8d1`) в `components/base/**`, `components/application/**` | выбор владельца; React Aria — доступность и тач; ничего из remlab |
| PRO | не используем и не коммитим | коммерческая лицензия запрещает публиковать исходники; репо публичный |
| Иконки | **Lucide** (ISC), не `@untitledui/icons` | лицензия иконок UUI запрещает распространение (в npm при этом написано MIT — противоречие, не рискуем) |
| Лицензии | `THIRD_PARTY_NOTICES.md`: коммит upstream, список скопированных файлов, MIT (UUI), Apache-2.0 (React Aria), OFL (Inter), ISC (Lucide) | требование лицензий |
| Стили | `styles/uui/{globals,theme,typography}.css` из upstream + `styles/brand.css` — единственное место бренда | вся семантика UUI ссылается на шкалы `brand` и `neutral` |
| Шрифты | заголовки Jost, текст Inter; `next/font/google`, latin + cyrillic, один раз в `styles/fonts.ts` для всех `<html>` | у посетителей — свои файлы, без запросов к Google; сеть нужна только CI при сборке |
| Тёмная тема | не в этом плане | решим в плане экранов |
| Ссылки-кнопки | два своих адаптера `RouterProvider`: публичный (next-intl: `useRouter` + `useHref` с префиксом локали) и админский (`next/navigation`, без локали) | ссылка должна быть верной и до загрузки JS, и при открытии в новой вкладке |
| Размер касания | обёртка над Button: на мобильном по умолчанию ≥ 44 px (у upstream по умолчанию `sm`) | ТЗ §21, ui-rules |

## Стиль (ориентир владельца — sallysbakingaddiction.com, берём настроение, не копируем)
Разбор главной (29.09, мобильный браузер; страница рецепта закрыта защитой от роботов — не обходим):
фото блюд — главное (карточки, 2 колонки на телефоне); светлый тёплый фон страницы + белые карточки;
крупные дружелюбные геометрические заголовки (у них платный Sofia Pro); кнопки-«таблетки» с мягкой
тенью; пастельные акценты (пыльная роза, песочный); много воздуха; мелкие метки категорий капсом.
Берём: фото-карточки, фон + белые карточки, кнопки-таблетки, пастельные подложки секций и меток,
крупные заголовки. Не берём: их логотип, «посыпку», фестончатую кромку, баннеры, рекламу.
- **Шрифты:** заголовки — **Jost** (бесплатный, близок к Sofia Pro, есть кириллица), текст — Inter.
- **Кнопки:** форма «таблетка» (полное скругление) — настройкой бренда, без правки компонентов upstream.

## Палитра — два варианта на выбор владельца (оба с нуля, проверены по контрасту WCAG)
Общее: фон страницы `#f7f4f1` (светлый тёплый), карточки белые; нейтральные — тёплые (лён/пергамент):
50 `#fcfaf6` · 100 `#f7f4ee` · 200 `#eae5df` · 300 `#d9d3cd` · 400 `#a8a29b` · 500 `#79736d` ·
600 `#5c5752` · 700 `#48433e` · 800 `#2d2926` · 900 `#1c1916` · 950 `#0d0b09`.
- **A (рекомендую) — олива + «румянец».** Главный — олива (масло, травы): 50 `#f7f8eb` · 100 `#ecf0d7` ·
  200 `#dae0b4` · 300 `#bfca8a` · 400 `#9fae5f` · 500 `#7d8e39` · **600 `#617122`** · 700 `#4d5b1a` ·
  800 `#3b4715` · 900 `#2e3711` · 950 `#181f07`. Пастельный акцент «румянец/персик» для подложек
  секций и меток: 50 `#fff4f1` · 100 `#fce8e2` · 200 `#f8d5cc` · 300 `#f0bfb2` · 500 `#c98472` ·
  700 `#884e40`. Своё лицо, «полезная домашняя еда», мягкость Sally's — за счёт пастели.
- **B — пыльная роза (ближе к Sally's).** Главный: 50 `#fff4f4` · 100 `#fee6e6` · 200 `#fbd0d0` ·
  300 `#f2b6b5` · 400 `#de9493` · 500 `#c17273` · **600 `#a15758`** · 700 `#844445` · 800 `#693535` ·
  900 `#512727` · 950 `#301515`; олива — вторым акцентом.
- Контраст: белый на кнопке A 5.4:1 / B 5.2:1 · текст бренда на белом A 7.4 / B 7.3 · текст меток на
  пастели 5.5 · основной текст на фоне 17:1 — всё ≥ WCAG AA. Бейджи «мёд/шафран» — шкала upstream `amber`.
- Выбор — на закрытой пробной странице `/admin/ui` на телефоне владельца: переключатель A/B. Итог
  фиксируется в `styles/brand.css` (одна правка файла).

## Скоуп — что входит
- Фундамент: зависимости, стили upstream, `brand.css`, шрифт, `utils/cx.ts` и что нужно Button
  (`utils/is-react-component.ts`), плагины из `globals.css` upstream (`@tailwindcss/typography`,
  `tailwindcss-animate`) — или вырезать неиспользуемое.
- Два адаптера роутера; `Button` + обёртка размера; замена кнопок на заглушках.
- **Проба на телефоне** (закрытая страница `/admin/ui`, `noindex`, переключатель палитры A/B): фото-карточки
  рецептов, поле поиска, чипы ингредиентов, переключатель «По рецепту / По ингредиенту», табы
  «Рецепт / Приготовление», нижняя кнопка действия —
  на бесплатных компонентах upstream, 320–375 px. Если бесплатного не хватает без борьбы со стилями —
  остановиться и вернуться к владельцу (запасной вариант — остаться на shadcn).
- Демонтаж: `@base-ui/react`, `class-variance-authority`, `components.json`, `components/ui/button.tsx`,
  `lib/utils.ts` (`cn`), временные токены `app/globals.css`.
- Правила и память: `ui-rules.md` под токены UUI, ADR-0015, `core/architecture.md`, anti-pattern №5.

## Скоуп — что НЕ входит
- Дизайн настоящих экранов, тёмная тема, PRO, иконки UUI, ничего из remlab.
