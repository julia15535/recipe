# Decisions — индекс решений (ADR)

Тексты решений — в томах `decisions/adr-0001-0050.md` (и следующих); здесь — одна строка на решение и
«по темам». Номер = max + 1, не переиспользуется (`ADR-DUP`); отменённое не стирается — новое решение
пишет «отменяет ADR-NNNN». Новое решение: текст — в текущий том (формат — `decisions/README.md`),
строка — сюда и в «По темам». Ссылки на другие решения в заголовке — в скобках (`ADR-AMBIGUOUS`).
