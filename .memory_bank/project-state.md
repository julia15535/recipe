  перевод (проверено на сайте 03.10). Кабинет `/admin` (вход через бота): рецепт текстом с ИИ-разбором, фото с
  кадрированием, публикация, английская версия; пробные экраны `/admin/ui`. Сертификат — Let's Encrypt (acme-companion).

  5 минут (`deploy/recipe-deploy.sh`), откат и карантин плохого образа — `core/deployment.md`.
- **Бэкап:** раз в сутки на сервере (≤ 7 дней) + локальная копия владельца (≤ 7 дней) +
  еженедельное восстановление (`deploy/local/`).
- **Рабочая сессия:** общая tmux-сессия `igor` (профиль VS Code `tmux-igor`); локально Node 24 через

  Решения на будущий план: отдельный раздел «Статьи» (список + страница статьи), свободный текст с заголовками и
  списками, НЕ подборки рецептов карточками; текст пишет владелец сама — вставляет в кабинете, ИИ только размечает
  (заголовки/абзацы/списки) и не пишет за неё (проверять сверкой текста до/после); EN — автопереводом после
  публикации, как рецепты (ADR-0029); «наглядные картинки немного» — несколько картинок внутри текста между

  места картинок.
