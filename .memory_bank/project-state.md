## Где
- **Прод:** https://mycoruja.food — каркас (заглушки `/ru`, `/en`, `/admin`) + пробные экраны для
  владельца `/admin/ui` (главная, поиск, рецепт на примерных рецептах), закрытые входом владельца через
  бота (`/admin/login`, выкачено 02.10, `f9bcf7c`, webhook включён); в кабинете — загрузка рецептов текстом
  (план `recipe-upload`, выкачено 02.10, `2365bab`); закрыт от индексации
  (`SITE_INDEXABLE=false`); сертификат Let's Encrypt с автопродлением (acme-companion).
- **Репозиторий:** `github.com/julia15535/recipe` (публичный), ветка `main`; push — по SSH ключом
  владельца, CI — GitHub Actions (`.github/workflows/ci.yml`).
- **Сервер:** общий зарубежный хост владельца за общим `nginx-proxy` (детали — только
  `.memory_bank/_secrets/ACCESS.md`). Контейнеры `recipe-web`, `recipe-db` с лимитами.
- **Деплой:** автоматический — CI публикует `ghcr.io/julia15535/recipe:stable`, сервер забирает каждые
  5 минут (`deploy/recipe-deploy.sh`), откат и карантин плохого образа — `core/deployment.md`.
- **Бэкап:** раз в сутки на сервере (≤ 7 дней) + локальная копия владельца (≤ 7 дней) +
  еженедельное восстановление (`deploy/local/`).
- **Рабочая сессия:** общая tmux-сессия `igor` (профиль VS Code `tmux-igor`); локально Node 24 через
  nvm, Postgres 17 — `pnpm db:up` (порт 5434).

## Ключевые решения (зафиксировано)
- Каталог: 11 разделов (Завтраки … Заготовки), рецепт в нескольких, один основной; ингредиенты — не
  структура каталога (ADR-0001, ADR-0018). URL — плоский `/{locale}/catalog/{slug}` (ADR-0017).
- Поиск: за лупой в шапке, отдельная страница; «По рецепту / По ингредиенту», мульти-выбор, иерархия
  ингредиентов, без ИИ (ADR-0002, ADR-0017).
- Ингредиенты с иерархией, самый конкретный тип, без брендов (ADR-0003).
- Пересчёт: посетитель вписывает своё количество основного ингредиента (без «−/+»), порции
  производные; якорь неизменен + таблица правил округления (ADR-0004, ADR-0016).
- **КБЖУ пока нет** (владелец 01.10; ADR-0019 приостанавливает ADR-0005); вместо него — теги
  «Особенности состава», которые ставит владелец. Публикация — только владелец (ADR-0006).
- Одна версия рецепта (ADR-0007). ИИ — только импорт/перевод/нормализация (ADR-0008).
- Рецепт добавляется вставкой любого текста, разбирает ИИ, владелец проверяет и публикует; разбор без ИИ —
  запасной путь; количества — точные дроби (ADR-0023, ADR-0024).
- RU основной + EN автоперевод, URL `/ru/…` `/en/…` (ADR-0009). Вход: свой Telegram-бот с подтверждением
  кодом, один владелец (ADR-0022; телефон из ADR-0010 отменён).
- Стек и слои (ADR-0011), БД и миграции (ADR-0012), кэш Cache Components (ADR-0013),
  CI/CD и прод (ADR-0014).
