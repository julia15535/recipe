# Добавление рецепта — Tier 1 сводка (ADR-0023, ADR-0024, ADR-0031)

## Как работает
- «Добавить рецепт»: вставить **как есть** (абзац, список, PDF) → «Разобрать» → ИИ раскладывает по полям (~1–10 с)
  → «Проверьте» и предпросмотр → «Сохранить черновик» / «Опубликовать» (`app/(admin)/admin/(protected)/recipes/_components/recipe-editor.tsx`).
- «Проверьте» (`ai-checks.tsx`): **нужно решить** (не рецепт, два основных, основной без точного числа — сохранить
  нельзя), **что сделал ИИ** (цитата сверяется с текстом), **замечания** («без пересчёта», ингредиент без числа).
- Есть список — ингредиенты только из него, несовпадения с шагами — замечаниями; нет — из текста с замечанием;
  повтор названия — замечание (ADR-0031, `lib/domain/recipe-text/ai-checks.ts`).
- Основной — только с пометкой автора «основной» (ИИ сверяется с текстом); нет — рецепт без пересчёта (ADR-0025).
  Ложки не переводятся в граммы. Правила — `lib/domain/recipe-text/from-ai.ts`, инструкция ИИ — `lib/server/ai/recipe-prompt.ts`.
- Сохраняется разбор с сервера (`recipe_imports` по id, `ai-actions.ts`), не данные из браузера.
- «Изменить» — аккуратный текст рецепта в том же поле; правите словами → «Разобрать» → замена (адрес и статус
  те же; вторая вкладка — «изменён в другой вкладке»).
- Сбой ИИ — сообщение, текст на месте, «Разобрать по старому формату» (`lib/domain/recipe-text/parse.ts`).
- Удалить можно только черновик. Запись сразу сбрасывает кэш сайта (ADR-0027). Публикация ставит перевод на
  английский, если его нет (ADR-0029); блок «Английская версия» — статус, «Перевести» / «Перевести заново».

## ИИ
Модель `openai/gpt-6-luna` через Vercel AI Gateway (env `AI_GATEWAY_MODEL`), ключ общий с sup2; ~$0.0006 за
рецепт; ≤ 30 разборов в час, один за раз; в журнал — без текста и ключа (`lib/server/ai/gateway.ts`).
