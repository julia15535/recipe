# Добавление рецепта — Tier 1 сводка (ADR-0023, ADR-0024)

## Как работает
- Кабинет `/admin` → «Мои рецепты» → «Добавить рецепт»: вставить рецепт **как есть** (абзац, список, заметка,
  PDF) → «Разобрать» → ИИ раскладывает по полям, ингредиентам, шагам и советам (~1–10 с) → «Проверьте» и
  предпросмотр как на сайте → «Сохранить черновик» / «Опубликовать» (`app/(admin)/admin/(protected)/recipes/_components/recipe-editor.tsx`).
- «Проверьте» (`app/(admin)/admin/(protected)/recipes/_components/ai-checks.tsx`): **нужно решить** (без этого сохранить
  нельзя: не рецепт, два основных, основной без точного числа), **что сделал ИИ** («полкило фарша» → 500 г — цитата
  сверяется с текстом; раздел), **замечания** (основной или «без пересчёта», ингредиент без числа).
- Основной — только с пометкой автора «основной» (ИИ сверяется с текстом); нет — рецепт без пересчёта (ADR-0025).
  Ложки не переводятся в граммы; «примерно 3 г» в скобках при ложках не показывается. Правила — `lib/domain/recipe-text/from-ai.ts`, инструкция ИИ — `lib/server/ai/recipe-prompt.ts`.
- Сохраняется разбор с сервера (`recipe_imports` по id, `app/(admin)/admin/(protected)/recipes/ai-actions.ts`), не данные из браузера.
- «Изменить» — аккуратный текст рецепта в том же поле; правите словами → «Разобрать» → замена (адрес и статус
  те же; вторая вкладка — «изменён в другой вкладке»).
- Сбой ИИ — сообщение, текст на месте, «Разобрать по старому формату» (`lib/domain/recipe-text/parse.ts`).
- Удалить можно только черновик. Любая запись сразу видна на сайте (`refreshPublicSite`, ADR-0027); у
  опубликованного — «Открыть на сайте».

## ИИ
Vercel AI Gateway, модель `openai/gpt-6-luna` (env `AI_GATEWAY_MODEL`), ключ общий с sup2; ~$0.0006 за рецепт;
не больше 30 разборов в час и один за раз; в журнал — только числа (`lib/server/ai/gateway.ts`).
