# Поиск — Tier 1 сводка

## Суть (ADR-0002)
- Главный сценарий продукта — **очень быстро найти конкретный рецепт**; особенно с телефона.
- Поиск — за **лупой в шапке** (решение владельца 01.10), отдельная страница `/{locale}/search`:
  состояние в адресе, всегда `noindex` (ADR-0017); на ней — **«По рецепту» / «По ингредиенту»**.
- По ингредиенту: один или несколько сразу (И), автокомплит (`тво… → творог`).
- **Иерархия:** «сыр» находит моцареллу, пармезан, чеддер и др.; «моцарелла» — только моцареллу.
- На компьютере форма — карточкой по центру; окно поверх страницы владелец отклонила (01.10).
- Уточнение без сложной формы — разделом (только разделы с рецептами, ADR-0020) и тегами, в т. ч.
  «особенностями состава» (ADR-0019):
  `курица + грибы → Горячее`, «Салаты + Белок». Раздел из каталога открывается с уточнением.
- Прототип на демо-данных: `/admin/ui/search` (`app/(admin)/admin/ui/_components/search-prototype.tsx`, e2e — `e2e/prototypes.spec.ts`).
- «Что приготовить из того, что есть дома» — не основной сценарий.
- На главной НЕ показывать огромный каталог ингредиентов.

## Правила
- **Без ИИ**: индекс по названиям, ингредиентам (с предками по иерархии), категориям, тегам,
  синонимам.
- Крупные цели касания, без desktop-dropdown (`ux.md`).
