# Поиск — Tier 1 сводка

## Суть (ADR-0002)
- Главное — **очень быстро найти конкретный рецепт**, особенно с телефона.
- За **лупой в шапке** (владелец 01.10), отдельная страница: состояние в адресе, `noindex` (ADR-0017);
  **«По рецепту» / «По ингредиенту»**.
- По ингредиенту: один или несколько сразу (И), автокомплит (`тво… → творог`).
- **Иерархия (со справочником):** «сыр» находит моцареллу, пармезан, чеддер и др.; «моцарелла» — только моцареллу.
- На компьютере форма — карточкой по центру; окно поверх страницы владелец отклонила (01.10).
- Уточнение — разделом (только с рецептами, ADR-0020) и тегами состава (ADR-0019): «курица + грибы → Горячее».
  Раздел из каталога открывает страницу раздела, не поиск (владелец 01.10).
- На сайте (ADR-0027): `/{locale}/search` — в браузере по индексу опубликованных рецептов языка страницы (EN — снимок, ADR-0029)
  (`components/search/recipe-search.tsx`, `lib/domain/search.ts`): нормализация (регистр, «ё»), все условия «И»,
  адрес `by`, `q`, `i`, `section`, `tag`; таблетки ингредиентов — из названий строк, сначала самые частые (12) и
  «Все ингредиенты» (`components/search/ingredient-chips.tsx`); прототип — тот же компонент.
- «Что приготовить из того, что есть дома» — не основной сценарий; каталог ингредиентов на главной не показывать.

## Правила
- **Без ИИ**: сейчас — подстрока в названии и в названиях строк ингредиентов, разделы и теги — фильтром
  (`lib/domain/search.ts`); предки по иерархии и синонимы — со справочником ингредиентов.
- Крупные цели касания, без desktop-dropdown (`ux.md`).

## Открыто
Иерархия ингредиентов и словоформы («Яйца»/«Яйцо» — пока разные таблетки) — со справочником ингредиентов;
серверный поиск — когда индекс перерастёт ~300 КБ; опечатки.
