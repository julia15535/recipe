# Сценарии — Tier 1 сводка

## Посетитель (без входа)
1. Главная → поиск «По рецепту» (название) или «По ингредиенту» (один/несколько, с иерархией) —
   либо категория → подкатегория → тег.
2. Уточнение категорией/тегом одним нажатием (тег сохраняется при смене категории).
3. Страница рецепта → «Рецепт»: пересчёт по порциям или «у меня X г» → КБЖУ обновляется.
4. «Приготовление» — шаги во время готовки.
5. Поделиться публичной ссылкой; переключить RU/EN.

## Владелец
1. Вход: телефон → подтверждение в Telegram.
2. «Добавить рецепт» → текст / голос / фото / PDF / Word / TXT + фото блюда → «Сформировать».
3. ИИ → черновик (+ EN-версия) → предпросмотр с подсвеченными неуверенными полями.
4. Правка → «Сохранить черновик» | «Опубликовать» | «Перегенерировать из исходников».
5. Правка опубликованного — меняет сам рецепт (без версий); EN обновляется ИИ.
6. Каталог в админке: категории и теги — добавить, удалить, объединить.

## Статусы рецепта
черновик → опубликован (только владелец). Детали — `auth-publishing.md`.
