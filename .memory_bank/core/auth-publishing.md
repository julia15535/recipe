# Вход и публикация — Tier 1 сводка

## Вход владельца (ADR-0022; телефон из ADR-0010 отменён)
- Один владелец — `OWNER_TELEGRAM_ID` в env сервера. Вход через своего бота `@mycoruja_recipes_bot`:
  «Войти через Telegram» → в боте «Старт» → тот же код, что на экране → «Подтвердить» → вкладка
  сама входит. С компьютера — QR. Сессия 30 дней, «Выйти» отзывает её.
- Закрыто всё `/admin` (кабинет и пробные экраны `/admin/ui`), открыт только `/admin/login`;
  проверка — `requireOwner()` в каждой странице и действии (`lib/server/auth/owner.ts`).
- Подсунутая ссылка не впускает: подтверждает только кнопка владельца, а сессию получает браузер,
  начавший вход (cookie привязки). Посторонним бот отвечает общей фразой без кода.
- Кабинет — строгая CSP с nonce (`proxy.ts`), рендер на каждый запрос (`app/(admin)/admin/layout.tsx`).
- Владельцу: включить облачный пароль Telegram (вход держится на её аккаунте).

## Публичный пользователь (без аккаунта)
Может: читать, искать, фильтровать, пересчитывать ингредиенты, переключать язык, делиться ссылкой.
Не может: добавлять, редактировать, удалять, публиковать. Кнопку «Добавить рецепт» не видит.
Сложные аккаунты, комментарии, оценки — не на первом этапе.

## Публикация (ADR-0006, ADR-0007)
- Статусы: черновик → опубликован. Опубликованный = проверенный владельцем.
- ИИ создаёт только черновик; без ручного подтверждения не публикуется.
- Одна актуальная версия: правка меняет сам рецепт, истории версий нет.
