# Добавление рецепта (ИИ-импорт) — Tier 1 сводка

## Суть
- Кнопка «Добавить рецепт» — только владельцу после входа; цель — без длинной ручной формы.
- Источники в любом сочетании, всё опционально: текст, голос (запись с телефона), фото/скриншот,
  PDF, DOC/DOCX, TXT, фото готового блюда → «Сформировать рецепт».
- Конвейер: исходники → извлечение текста (STT, OCR/vision, парсинг документов) →
  ИИ-структурирование → **черновик** → предпросмотр → ручная правка → публикация.
- ИИ определяет: название, описание, категорию и подкатегории, теги, порции, время, ингредиенты с
  количествами и единицами, основной ингредиент, шаги, данные для КБЖУ.

## Правила
- **Не выдумывать** критичные данные; неуверенные поля выделять в предпросмотре.
- ИИ создаёт только черновик; публикует владелец вручную (ADR-0006).
- Предпросмотр почти как на сайте, редактируется всё; кнопки: Сохранить черновик · Опубликовать ·
  Перегенерировать из исходников.
- EN-версия генерируется ИИ при добавлении/правке, правится вручную (ADR-0009).
- Результаты ИИ сохраняются в БД; дальше — обычный код (ADR-0008).
- Контекст для ИИ: домашняя еда с разумным балансом, вкус важнее диеты.
