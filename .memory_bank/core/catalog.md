# Каталог — Tier 1 сводка

## Суть (ADR-0001; верхний уровень — ADR-0018)
- **11 разделов:** Завтраки · Супы · Салаты · Горячее · Гарниры · Закуски · Выпечка · Десерты ·
  Соусы · Напитки · Заготовки («Вторые блюда» → «Горячее»; «Разное» убрано и разнесено).
- Рецепт — в **одном или нескольких разделах**, один основной (первый в строке разделов рецепта, подпись карточки; крошки — на странице раздела).
- **Ингредиенты — не структура каталога** (они работают в поиске).
- Цель (в коде пока нет): подкатегории по мотивам gotovim-doma.ru (ориентир, не копия), до 3+ уровней; структура
  **редактируется из админки** (добавить, удалить, объединить с переносом рецептов и редиректом).
- URL раздела — плоский `/{locale}/catalog/{slug}`, slug по языкам (`lib/server/recipes/public.ts`); история slug и 301 — позже.
- В БД (ADR-0023): разделы и теги — постоянные id/code + локализации; слова распознавания — `lib/domain/catalog.ts`.

## Теги
- **Тематические** (цель; «На скорую руку», «Постное»…) — для поиска и фильтров, на рецепте не видны.
- **Особенности состава** (ADR-0019): Белок · Клетчатка · Полезные жиры · Мало сахара · Железо —
  ставит владелец; на рецепте рядом со временем, у каждого свой цвет, без подписи (ADR-0021); фильтр в поиске.
- Цель: категории, подкатегории и теги — индексируемые страницы (SEO); сейчас есть страницы разделов, сайт закрыт.

## UI
Каталог — в закреплённой шапке на страницах сайта (`components/site-header.tsx`): 11 мест, пустые
бледные и не ссылки (ADR-0020); компьютер — лента, телефон — значок «меню» → нижний лист; раздел →
страница раздела сразу с рецептами, текущий выделен (`app/(public)/[locale]/catalog/[slug]/page.tsx`); поиск — лупой.
Рецепт: разделы строкой ссылок. Большая структура — в каталоге и SEO-футере (футер — позже).

**Tier 2:** `../domain/catalog-structure.md` — полное дерево и стартовые теги (сид).
