# Каталог — Tier 1 сводка

## Суть (ADR-0001)
- Основная классификация — **по типу блюда**, 10 верхних категорий: закуски, салаты, супы, вторые
  блюда, выпечка, десерты, напитки, соусы, заготовки, разное.
- **Ингредиенты — не структура каталога** (они работают в поиске).
- Подкатегории — по мотивам gotovim-doma.ru (ориентир классификации; интерфейс и сложность НЕ
  копируем). Глубина до 3+ уровней: Салаты → Классические → Оливье.
- Структура **редактируется из админки**: добавить, удалить, объединить (с переносом рецептов и
  редиректом старых URL).

## Теги
- Отдельная сущность: «На скорую руку», «Постное», «Для мультиварки» и т. п.
- Тег внутри категории: `Супы → Полезное питание` показывает полезные супы; одним нажатием
  переключаем категорию — тег остаётся активным.
- Категории, подкатегории и теги — отдельные индексируемые страницы (SEO).

## UI
Главная: поиск + основные категории. Большая структура каталога — в каталоге и SEO-футере, не в
основном интерфейсе.
