# Каталог — Tier 1 сводка

## Суть (ADR-0001; верхний уровень — ADR-0018)
- **11 разделов:** Завтраки · Супы · Салаты · Горячее · Гарниры · Закуски · Выпечка · Десерты ·
  Соусы · Напитки · Заготовки («Вторые блюда» → «Горячее»; «Разное» убрано и разнесено).
- Рецепт — в **одном или нескольких разделах**, один основной (хлебные крошки, порядок).
- **Ингредиенты — не структура каталога** (они работают в поиске).
- Подкатегории — по мотивам gotovim-doma.ru (ориентир классификации; интерфейс и сложность НЕ
  копируем). Глубина до 3+ уровней. Структура **редактируется из админки** (добавить, удалить,
  объединить с переносом рецептов и редиректом).
- URL раздела — плоский `/{locale}/catalog/{slug}`, slug по языкам, старые → 301 (ADR-0017).

## Теги
- **Тематические** («На скорую руку», «Постное», «Для мультиварки»…) — для поиска и фильтров; на
  странице рецепта не видны. Тег внутри категории: `Супы → Полезное питание`.
- **Особенности состава** (ADR-0019): Белок · Клетчатка · Полезные жиры · Мало сахара · Железо —
  ставит владелец по своему суждению; видны на рецепте с подписью «не расчёт КБЖУ»; фильтр в поиске.
- Категории, подкатегории и теги — отдельные индексируемые страницы (SEO).

## UI
Главная: каталог первым — лента / нижний лист (`components/catalog/catalog-nav.tsx`), поиск — лупой.
Рецепт: разделы строкой ссылок. Большая структура — в каталоге и SEO-футере.
