# UX и mobile-first — Tier 1 сводка

## Принципы (ТЗ §1, §21)
- Mobile-first — принципиально. Минимум лишнего, максимально быстрая навигация.
- Одной рукой: найти, открыть, вписать своё количество, переключить вкладки, надиктовать рецепт,
  загрузить фото, проверить черновик, опубликовать. Без мелких элементов и desktop-dropdown.
- Визуально: домашняя, современная, преимущественно полезная еда (не строгий ЗОЖ).

## Экраны (решения владельца 01.10; детали — Tier 2)
- **Шапка** закреплена на всех страницах: название · лупа «Поиск» · язык (`components/site-header.tsx`).
- **Главная:** первым — каталог из 11 мест, пустые бледные (ADR-0018, ADR-0020); ниже — «Подборка
  недели», «Популярное» внизу (на сайте пока скрыто).
- **Раздел:** сразу рецепты раздела, без поиска; текущий раздел выделен в каталоге.
- **Поиск:** отдельная страница, на компьютере — карточкой по центру.
- **Рецепт:** строка «время + цветные теги состава» (ADR-0021), вкладки «Рецепт / Приготовление»,
  «~ N порций», своё количество основного ингредиента (ADR-0016); КБЖУ пока нет (ADR-0019).
- Прототипы: `app/(admin)/admin/ui/`, проверки — `e2e/prototypes.spec.ts`.

## Критерии успеха (решение владельца, по порядку)
1. Очень быстро найти рецепт. 2. Удобно пользоваться во время готовки. 3. Очень быстро добавлять.
4. Удобно делиться. SEO — вторично.

## Открыто
«Удобно у плиты» (экран не гаснет, крупный шрифт, отметки сделанного?) и «удобно делиться»
(системное «Поделиться», превью ссылки) — решить с владельцем.
