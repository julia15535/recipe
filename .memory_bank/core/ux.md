# UX и mobile-first — Tier 1 сводка

## Принципы (ТЗ §1, §21)
- Mobile-first — принципиально. Минимум лишнего, максимально быстрая навигация.
- Одной рукой: найти рецепт, выбрать категорию, открыть, вписать своё количество
  основного ингредиента, переключить «Рецепт/Приготовление», записать голосовой рецепт, загрузить
  фото, проверить ИИ-черновик, опубликовать.
- Без мелких элементов и сложных desktop-dropdown.
- Визуально: домашняя, современная, преимущественно полезная еда (не строгий ЗОЖ).

## Главная (решения владельца 01.10, ADR-0018)
Шапка: название · лупа «Поиск» · язык. Первым — каталог из 11 разделов: лента на всю ширину
(компьютер, от 1024 px), кнопка «Каталог» → нижний лист (телефон и планшет). Ниже — «Подборка недели» (выбирает владелец), «Популярное» — в самом низу, пока
скрыто. Владельцу — «Добавить рецепт» (после входа).

## Страница рецепта (01.10)
- Шапка: разделы строкой ссылок, название, описание, время, «Особенности состава» (ADR-0019), фото.
- Таб **«Рецепт»**: «Ингредиенты»; у основного — поле «своё количество», остальное и порции
  пересчитываются (ADR-0016), без «−/+». Порции — справа (компьютер), под списком (телефон).
- Таб **«Приготовление»**: шаги, только текст. Одна фото, без видео. **КБЖУ пока нет** (ADR-0019).
- Прототипы (демо-данные): `app/(admin)/admin/ui/`, компоненты `components/catalog/catalog-nav.tsx`, `e2e/prototypes.spec.ts`.

## Критерии успеха (решение владельца, по порядку)
1. Очень быстро найти рецепт. 2. Удобно пользоваться во время готовки. 3. Очень быстро добавлять.
4. Удобно делиться. SEO — вторично.

## Открыто
Что конкретно входит в «удобно во время готовки» (экран не гаснет, крупный шрифт, отметки
сделанного?) и «удобно делиться» (кнопка системного «Поделиться», превью ссылки) — решить с
владельцем в плане экрана рецепта.
