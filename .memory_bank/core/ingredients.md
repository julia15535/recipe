# Ингредиенты и КБЖУ — Tier 1 сводка

## Иерархия (ADR-0003)
- Сыр → Моцарелла, Пармезан, Чеддер, Сливочный сыр; Масло → Сливочное, Оливковое, Подсолнечное.
- В рецепте — максимально конкретный тип, если он влияет на результат блюда.
- Бренды и товарные позиции — не нужны на первом этапе (база расширяема позже).
- Иерархия работает в поиске (родитель находит потомков) и может нести правила округления.

## Единицы
- Базовые для расчёта: г, мл, шт. В интерфейсе: кг, г, мл, л, шт., ст. л., ч. л., стакан, щепотка.
- Эквивалент в г/мл определяется один раз (при импорте ИИ: «1 среднее яйцо ≈ 55 г») и
  сохраняется; для условных — сохранённое приближение.
- Количество в строке рецепта — точное, диапазон («½–1 ч. л.») или нет с пометкой «по желанию» (Tier 2).

## КБЖУ (ADR-0005 — приостановлено ADR-0019)
- **Владелец 01.10: «пока без кбжу»** — не считаем и не показываем. При возврате рекомендованный
  старт — ккал от автора × коэффициент (без справочника); модель ниже — вариант «из базы».
- Ориентировочно: усреднённые значения по типу ингредиента на 100 г; бренд, упаковка, точная
  жирность не учитываются. Явный тип (моцарелла, оливковое масло) — свои значения.
- Показывать минимум: всё блюдо и одна порция; пересчитывается математически вместе с порциями и
  количествами, без ИИ.
