# Пересчёт рецепта — Tier 1 сводка

## Суть (ADR-0004)
- Режимы: **по порциям** (4 → 6, коэффициент 1,5) и **по имеющемуся ингредиенту** (творог 500 → 220 г,
  коэффициент 0,44) — якорем может быть почти любой измеримый ингредиент, не только основной.
- **Кулинарно разумно**, не только математически.
- **Якорь неизменен:** введённое пользователем (мясо = 900 г) остаётся ровно; остальное — от него.
- Неудобные значения (яйцо = 1,4 шт.) — по **таблице правил округления по типу ингредиента**:
  можно ли округлять, минимальный шаг, вверх/вниз, допустимое отклонение пропорции.
- Ориентиры владельца: яйца — до целых по отдельному правилу; сахар и соль — чаще вниз; специи — до
  практичных мер; мясо, творог, мука — введённое не менять.

## Правила
- Пересчёт и КБЖУ — программно, мгновенно, без ИИ.
- Правила округления — в таблице БД, применяются кодом; ИИ не решает каждый раз.
- **Порядок работ:** таблицу правил проработать **отдельным этапом ДО реализации пересчёта**
  (нормы предметной области → разбор с Codex и источниками).
