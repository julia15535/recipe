# Статьи — Tier 1 сводка (ADR-0034)

## Как работает
- Кабинет → «Мои статьи» → «Новая статья»: название (пишет владелец) + текст как есть → «Разобрать» → ИИ
  только отмечает строки: заголовок / абзац / пункт списка (`lib/server/ai/article-markup.ts`), слова код берёт из её
  строк — изменить их ИИ не может; разметка не легла — разбор без ИИ сам, с замечанием; ИИ недоступен — кнопка
  «Разобрать без ИИ» (`lib/domain/article-text/plain.ts`: «#» заголовок, «-»/«1.» пункт, пустая строка — граница).
- Фото: после сохранения — «Добавить фото сюда» между блоками (кадр 4:3, как у рецептов — ADR-0028); в тексте место
  фото — строка «[Фото Q7K2]» (код постоянный); перенос метки в «Изменить» без смены слов — без нового разбора ИИ
  (`lib/domain/article-text/edit.ts` `remap`). До 10 фото, подпись — по желанию; метку убрали — фото «без места».
- Связанные рецепты — чипами в кабинете; на сайте только опубликованные с обеих сторон.
- Сайт (только RU): `/ru/articles` (список), `/ru/articles/{slug}`; ссылка «Статьи» — в шапке (компьютер) и в меню
  каталога (телефон), блок на главной под «Новыми рецептами», «Статьи по рецепту» на рецепте. `/en/articles` — нет
  (английский — следующий план `articles-en`).

## Хранение
`articles` (`source_text` с метками + проверенный `body` jsonb по Zod-схеме `lib/server/articles/body-schema.ts`),
`article_localizations`, `article_photos` + файлы, `article_recipes`, `article_imports` — миграция 0010.
