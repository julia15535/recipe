# UI-правила

> Стек — Next.js 16 + Tailwind 4 + shadcn/ui base-nova (`@base-ui/react`), ADR-0011. Токены темы —
> `app/globals.css`. Экраны и сценарии — `.memory_bank/core/ux.md`.

## Mobile-first — принципиально (ТЗ §21)
- Базовые стили — мобильные (проверка на 375 px), расширяем брейкпоинтами вверх.
- Всё ключевое — одной рукой: крупные цели касания (не меньше ~44 px — у shadcn-кнопок по умолчанию
  32 px, добавляй `h-11`), основные действия в зоне большого пальца.
- **Без мелких элементов и сложных desktop-dropdown**: выбор — чипы, сегменты, нижние листы.
- Минимум лишнего: большая структура каталога — в каталоге и SEO-футере, не в основном интерфейсе.
- Страница рецепта должна быть удобна у плиты: компактная шапка, табы «Рецепт / Приготовление».

## Дизайн-токены
- Только **семантические** токены темы (напр. `bg-primary`, `text-muted-foreground`, `bg-card`).
- Запрещены сырые цвета (`bg-white`, `text-gray-*`, hex в классах) — ломают тему/тёмный режим.

## Компоненты
- Переиспользуй компоненты дизайн-системы; не правь сгенерированные ui-примитивы напрямую.
- Иконки — из одного набора (консистентность).
- Headless-UI (base-ui/Radix): пункты меню активируй `onClick` (не `onSelect`); части-обёртки
  (`GroupLabel` и т.п.) держи внутри обязательных родителей (`Group`) — иначе рантайм-краш. Подробнее
  и другие грабли — `.memory_bank/anti-patterns.md`.

## Состояния
Каждый экран покрывает `loading` / `error+retry` / `empty` / `success`.
Поиск отвечает мгновенно: без блокирующих спиннеров на каждый символ.

> Доменные ограничения (тон, дисклеймеры и т.п.) — выноси в отдельный path-scoped rule,
> см. `.memory_bank/guides/how-to-write-rules.md`.
